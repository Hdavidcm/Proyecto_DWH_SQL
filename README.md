# Proyecto_DWH_SQL
Desarrollo de un Data Warehouse (DWH) moderno en SQL Server, incluyendo procesos ETL, modelado dimensional y analítica de datos.
Este proyecto se llevó a cabo siguiendo el video tutorial del canal de YouTube **Data with Baraa** y representa una aplicación práctica de los conocimientos adquiridos durante el **Certificado Profesional de Microsoft SQL Server** ofrecido por **Coursera**.
